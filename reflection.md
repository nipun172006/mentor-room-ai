# Reflection

The strongest part of this project was giving every persona a different way of thinking, not just a different biography. Anshuman’s prompt works best when it turns an unclear ambition into a measurable outcome and a high-impact next action. Abhimanyu’s prompt is more useful when motivation is treated as a system involving routine, environment, feedback, and mentorship. Kshitij’s prompt feels most distinct when it begins with intuition, uses a tiny example, and checks the learner’s understanding. The few-shot examples made these differences much more reliable than adjectives such as “friendly,” “smart,” or “motivational” could.

The GIGO principle became very practical while building the prompts. A generic instruction produced the same polished coaching language for every mentor. Better input required evidence: public talks, profile details, teaching accounts, recurring ideas, and constraints against invented claims. It also required specific output rules. Asking for a practical action, a short answer, and one useful follow-up question shaped the result more than simply asking the model to “sound like” someone. The prompt is therefore both context and a small quality-control system.

The biggest challenge was representing real people fairly. A language model can easily turn a few facts into confident fictional stories or quotations. Each prompt now says that it is an educational simulation, forbids private claims and guarantees, and grounds the persona in publicly documented professional themes. This makes the chatbot slightly less theatrical, but much more honest.

If I improved the project further, I would run a blind evaluation with people familiar with the three educators. I would prepare the same ten questions for every persona, score the answers for authenticity, usefulness, factual safety, and distinctiveness, and revise examples that produce overlap. I would also add optional streaming responses and store anonymous thumbs-up/down feedback without saving conversation content. For this assignment, however, the current version keeps the product understandable: one React interface, one small server route, three inspectable prompts, and a clear feedback loop from user question to persona-specific response.
